## Evidence requirements

- Link only real, public issues and pull requests after publication.
- Credit the person and quote feedback only with appropriate consent.
- Require contributors to remove CVs, credentials, session files, screenshots with personal data, and private application details.
- Use synthetic fixtures for bug reproduction whenever possible.
- AI-assisted contributions remain the submitting human's responsibility; generated volume is not community adoption.
- Record review substance, tests, and release inclusion rather than counting raw commits.
