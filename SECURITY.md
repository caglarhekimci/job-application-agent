# Security status and reporting

This is an early local prototype, not an audited production service.
Private vulnerability reporting was enabled and its saved setting verified on
2026-09-19 UTC. Use the repository's
[security advisory page](https://github.com/caglarhekimci/job-application-agent/security/advisories)
to privately report a vulnerability. Include a minimal synthetic reproduction and affected commit. Do not
attach real CVs, session URLs, credentials or application databases.

No support response time or independent security audit is promised. Do not open a
public issue containing exploit details or personal data.

See docs/THREAT_MODEL.md for assumptions, controls and unverified boundaries.
Critical unauthorized sharing, submission or factual misrepresentation blocks
release regardless of aggregate test accuracy.
